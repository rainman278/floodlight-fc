# Floodlight FC

Four-a-side floodlit football for iPhone. Static files only — host anywhere.

## Put it online (GitHub Pages, free)
1. Create a new public repo, e.g. `floodlight-fc`.
2. Upload every file in this folder to the repo root.
3. Settings → Pages → Source: Deploy from a branch → `main` / root → Save.
4. Wait ~1 minute; it's live at `https://<your-username>.github.io/floodlight-fc/`.

## Install on iPhone
Open the link in Safari → Share → Add to Home Screen. It launches full-screen with its own icon and works offline after the first load.
